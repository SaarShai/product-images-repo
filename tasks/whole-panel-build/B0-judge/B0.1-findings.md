# B0.1 findings — L1 geometry layer, measured on the anchors

## Experiment
Registered each combined anchor (artwork at exact SVG `<image>` transform onto the viewBox
canvas) and computed deterministic, model-free geometry signals, paired with the user labels.

## Result — coarse L1 metrics do NOT separate PASS from FAIL
| anchor | label | alpha coverage | non-white paint_cov | bottom paint |
|---|---|---|---|---|
| princess-narrow-01 | PASS | 1.000 | 0.636 | 0.847 |
| space-stabilizer-01 | PASS | 1.000 | 0.234 | 0.496 |
| space-narrow-panels-01 | PASS | 1.000 | 0.717 | 0.690 |
| window-fit-01 | PASS | 1.000 | 0.785 | 0.564 |
| **princess-panels-FAIL-01** | **FAIL** | 1.000 | 0.473 | 0.470 |

- **alpha coverage = 1.0 for all** — the FAIL's "doesn't reach the bottom" is a WHITE gap inside an
  opaque raster, not transparency. Transparency-based coverage is blind to it.
- **non-white paint is noisy** — the FAIL (0.47) outscores the stabilizer PASS (0.23), because PASS
  panels legitimately contain white (margins, sky, light backgrounds). No global threshold separates.

## Conclusion (validates the 3-layer design)
- **L1's real job** = (a) provide the **canonical registered overlay**, (b) catch **gross** geometry
  failures (paint far outside the contour, opening grossly mislocated) and **per-opening** cleanliness
  — NOT subtle whole-panel judgments.
- **L3 (VLM over the registered overlay + high-DPI crops) is REQUIRED** for the FAIL's actual defects:
  under-fill vs the *contour* bottom, a fairy *inside the red band*, painted wings off the *finger-hole
  cutouts*, top silhouette vs the *green top-contour*. These are registered-semantic, not global-pixel.
- Evidence the VLM layer works: reading each anchor's `overlay.png` reproduced all 5 labels
  (princess-FAIL → FAIL on bottom-gap + spires-through-green + fairies-over-red; the 4 PASS → PASS).

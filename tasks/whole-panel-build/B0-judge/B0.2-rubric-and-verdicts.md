# B0.2 — L3 vision rubric + verdicts (judge reads the REGISTERED overlay)

The judge looks at `overlay.png` (artwork + guide lines in true SVG coords) and per-cutout crops,
then checks each rule below. Geometry math (L1 per-opening) is the hard floor; this L3 layer catches
the registered-semantic defects L1 can't (proven in B0.1). **This rubric encodes the USER's criteria —
it needs user validation.**

## Checks (each PASS/FAIL with the registered evidence)
- **A. Fill-to-contour** — art fills the outer-contour interior; no white/empty gap inside the contour
  (esp. the bottom). [catches "doesn't reach the bottom"]
- **B. Cutout fit** — for each cutout: an *empty* cutout reads as clean background with a **bleed margin**
  and a soft **rim/bevel** leaning in; a *feature* cutout (e.g. arched window) has the painted feature
  sitting ON the cutout. The painted opening aligns with the cut. [catches cutout-misalignment]
- **C. Keep-clear (red)** — no recognizable/focal motif inside a red keep-clear zone; only quiet texture.
  [catches "fairies cropped in the red band"]
- **D. Top-contour (green)** — the illustration's top silhouette follows the green top-contour guide.
- **E. Arch fit (orange)** — central door/window/landmark fits the orange saloon-arch + door-flap outlines.
- **F. Margin / seams** — bleed margin between art and cut/cutout lines; no focal element split by a
  blue fold/seam or a panel seam (skyline DON'T rule).
- **G. Style** — one coherent painted illustration in the reference style (not collage/procedural).
- **No guide lines baked into the artwork.**

Verdict = **PASS** only if A–F hold (geometry/placement) AND G acceptable; else **FAIL** + failing checks.

This directory contains regenerable round-7 x4 gate overlays and D5 hole-gate diagnostic crops, with the compact D5 crops retained as review evidence and large overlays ignored. Regenerate the gate outputs with `scripts/gates/gate_battery.py --rgba <x4-rgba> --source <raw-x4> --bg-color '#00FF00' --profile print --out-dir <gate-dir>` using the corresponding files from `../x4/`; `battery.json` is the tracked proof for every run, including the paths and measured verdicts.

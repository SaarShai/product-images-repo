This directory contains regenerable review packs: full-resolution copies, dark/white/magenta composites, D5 gate crops, and deterministic junction crops; only compact gate/junction crops are retained while fullres and composites remain local. Regenerate each pack with `scripts/review_pack.py --final <x4-final> --raw <x4-raw> --out-dir <review-dir> --gate-dir <gate-dir> --n-crops 6 --crop-size 96`; the tracked `manifest.json` files are the proof inventory and point back to the tracked gate `battery.json` results.

# Styled Candidate Eval Rubric

Score 0-5. Threshold for showing as a styled candidate: 4.0.

Required blocking criteria:

- The candidate was generated with the actual reference images or style-packet
  sheets attached, not from prose alone.
- It reads as watercolor/gouache with visible paper texture, pigment bloom,
  soft washes, irregular hand-painted edges, and non-mechanical highlights.
- It uses the reference object vocabulary: candy cane stripes, rounded ornament
  candy shading, holly/berry warmth, frosted pale blue sugar/snowflake texture.
- It is candy/icing/gingerbread decoration only inside the cutouts. No miniature
  houses, buildings, windows, doors, facades, chimneys, villages, signs, words,
  labels, or text.
- It does not look like procedural placement, flat vector art, palette-only
  recoloring, sprite/crop collage, or a local mask-fill script.
- It can be shown alongside an exact mask/containment report; geometry green
  alone is not enough, but visible style green is required.

Failure case:

The earlier `d1`-`d6` procedural previews fail this rubric even though they have
zero outside-mask pixels, because they were generated by local Pillow geometry
scripts, not attachment-aware reference-style image generation, and their style
is too flat/procedural.

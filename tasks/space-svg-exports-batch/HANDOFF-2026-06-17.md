## Root Cause Of Current Drift

The adapted image in the user's latest overlay is not a true adaptation of the
approved geometry. It is a model redraw that approximated the panel from prompt
constraints.

The overlay is not the problem. The dashed contour is exposing the mismatch:

- top notch is deeper/wider than the SVG contour;
- long slot is taller/straighter and shifted;
- circular cutout is not at the SVG coordinate;
- panel/body registration differs vertically;
- controls moved/changed relative to the approved map.

Secondary issue: the local diagnostic style script uses a different output size
(`940x1506`) from the approved exact export (`900x1442`). The aspect ratio is
nearly the same, so that alone does not explain the visible cutout drift, but it
confirms the style path was not "take the approved geometry and only restyle it."

Primary cause: prompt-only redraw cannot be trusted for production geometry.
The model must not define cutout geometry. SVG does.

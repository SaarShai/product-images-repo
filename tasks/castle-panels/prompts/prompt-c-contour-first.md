# Prompt C - Contour-First / Illustration-Led

Create a new whimsical watercolor castle illustration for a two-panel die-line
template using the uploaded references.

Reference usage:
- Style reference: primary style, palette, and mood reference.
- Raster template: structural panel template.
- Contour examples: examples showing how the top contour should trace the castle
  silhouette.
- SVG template: authoritative geometry reference for the panel shape, safe area,
  slot, exclusion zones, and divide when available.

Primary visual objective:
The result should look like a custom-shaped fairytale castle panel whose top
cut-line has been designed around the castle skyline.

Style:
Closely match the watercolor castle reference: soft storybook watercolor, cream
and ivory towers, peach/coral/terracotta roofs, delicate golden windows,
blue-grey shading, magical glow, tiny whimsical creatures, airy white background,
refined but child-friendly detail.

Composition:
Create a tall castle scene across two sub-panels with a rich upper skyline of
towers and spires. The scene should include a layered arrangement of castle
forms with varied heights so the top silhouette is interesting and elegant.

Top contour:
This is especially important. Design the top contour so it traces the castle
skyline in a natural, graceful way. Let the contour rise and fall around major
roof peaks, towers, and spires. Use the contour-example images as the behavioral
reference for how the contour should feel.

The top contour must:
- follow major silhouette changes
- feel custom to the castle
- be smooth and printable
- keep a small clean clearance from the illustration
- avoid unnecessary fussiness
- avoid tiny bumps caused by minor details

Do not make the contour follow small birds, butterfly wings, fairy wings, flags,
or other tiny details. Those elements should remain inside the composition and
not define the die-line.

Template accuracy:
Follow the SVG geometry exactly when available. If no SVG is available, follow
the raster template as the available guide for:
- overall width and height
- safe area
- horizontal panel divide
- central slot
- exclusion areas
- blank outer margin

Safe area:
All important content must remain within the safe area. Leave the area between
safe area and cut line as a clean margin.

Exclusion zones:
The red-rectangle areas are no-feature zones. No specific focal element may
appear there or be cropped there. Only generic background material may occupy
those zones.

Slot:
The central slot must remain visually clear and must not intersect any focal
element.

Divide:
The horizontal panel split must not cut important elements. Arrange the castle so
that architectural transitions work with that divide.

Scene content:
Include similar visual ingredients to the style reference:
- many elegant castle towers
- varied spires
- crenellated walls
- glowing windows
- fairies
- birds
- butterflies
- soft floral base
- magical atmosphere

Position all specific elements carefully so they are not cropped by the
horizontal divide, the central slot, or the exclusion zones, and so they remain
within the safe area.

Output:
Produce the final illustration with the clean final black cut-line shape and
panel structure visible, but remove all temporary dashed guide lines and
annotations.

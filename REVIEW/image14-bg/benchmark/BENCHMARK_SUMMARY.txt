FACTS SUMMARY:
---------------

1. Overcut tolerance: transparent_background wins decisively on colored-
   pixel cleanup (3.92% false transparency). rembg is worst (39.24%).

2. Edge quality: transparent_background + carvekit have bright, clean
   fringes (173.8+ luma). color-to-alpha variants show dark fringing
   (52-55 luma), rembg intermediate.

3. Alpha gradation: Only transparent_background (52.95%) and color_to_alpha_soft
   (92.28%) maintain soft alpha transitions. Others are binarized (0/255 only).

4. File sizes: color_to_alpha_soft largest (2.5M, due to soft alpha data);
   rembg smallest (1.3M, likely via compression of binarized alpha).

5. No single "winner" across all metrics:
   - Best overcut:    transparent_background
   - Best fringe:     carvekit (tied with transparent_background)
   - Softest alpha:   color_to_alpha_soft
   - Smallest file:   rembg

Performance notes:
  - transparent_background: ~5 sec (GPU/MPS inference)
  - rembg:                  ~3 sec (fast ONNX inference)
  - carvekit:               ~10-15 sec (larger model)
  - color_to_alpha:         <1 sec (no ML, pure numpy)

User should review comparison boards against actual use case:
  - Precision removal (watercolor fine details):
    → transparent_background or carvekit
  - Soft artistic transitions:
    → color_to_alpha_soft (GIMP algorithm)
  - Speed + acceptable quality:
    → rembg

# LAW: reference beats prose

Core law 1 of the pipeline: **drive generation with reference IMAGES (+ geometry), never a
written description alone.** A missing reference is generated as a precursor rather than
substituted with prose. This is *why* Stage 1a exists at all — the style packet is the
mechanism that turns raw refs into attachable image evidence so the model styles from
pictures, not words.

Cited source: `docs/PIPELINE.md` (Core laws — law 1). Governs [[gather-references|gather-references]]
and the whole stage.
